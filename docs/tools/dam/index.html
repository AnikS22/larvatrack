Sleep & Activity (DAM)

Turns raw TriKinetics Drosophila Activity Monitor files into activity and sleep per fly, then compares groups. Sleep is any run of at least 5 minutes with no beam crossings.

How it works
  1. Upload one or more MonitorN.txt files from DAMSystem3 (1-minute bins).
  2. Say which tubes belong to which group, e.g. Male control: 1-8.
  3. Each fly's data stops at its death, so dead flies don't read as asleep. Untick any tube to leave it out. Every number updates.
  4. Pick a measure to graph. Download the per-fly table as CSV.
