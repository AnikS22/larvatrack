Climbing (negative geotaxis)

Tap the vial so the flies fall to the bottom; healthy flies climb straight back up. This scores where every fly is, second by second, in four equal quadrants from Quadrant 1 (bottom) to Quadrant 4 (top).

How it works
  1. Upload the video. Scrub to the moment the flies land after the tap and press This is 0 s.
  2. Vials: drag a box over each vial, from the bottom of the plug to the bottom of the vial. Name each vial's genotype.
  3. Flies: for each second, click every fly. Click a circle to remove it.
  4. Save the trial, then do the next video. Edit any saved trial to correct it later.
