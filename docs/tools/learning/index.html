Learning & memory (T-maze)

Scores olfactory conditioning: after an odor is paired with a shock, do flies avoid that odor when given the choice? Turns T-maze counts into a Performance Index and compares genotypes such as dunce and wild type.

The biology

Flies learn to associate an odor (CS+) with an electric shock and later avoid it, while a second odor (CS−) is presented without shock. The memory is formed in the mushroom bodies and depends on cAMP signalling.

dunce was the first learning mutant found in a fly (Dudai et al., 1976). It lacks a cAMP phosphodiesterase, so cAMP stays high and conditioning barely sticks: dunce flies learn poorly and forget fast. Wild-type (Canton-S) flies score high immediately and keep part of the memory for hours.

How to use it
  1. For each T-maze test, type the genotype, the retention interval (e.g. 0 min for learning, 3 h for memory), a replicate number, and how many flies went to each arm.
  2. Run the two reciprocal halves (odor A shocked, then odor B shocked) as two rows with the same replicate number: the tool averages them, which cancels any innate odor preference.
  3. Edit any cell to correct it, or delete a row. Paste rows straight from a spreadsheet with Paste rows.
Reading the results

PI = 100: every fly avoided the shocked odor. PI = 0: a 50/50 split, no learning. Negative PIs mean flies preferred the shocked odor (usually noise).

Compare genotypes at the same interval, and the same genotype across intervals to see forgetting. Each replicate is one dot on the chart.

The statistics half PI = 100 × (flies in CS− arm − flies in CS+ arm) / (all flies that chose) PI = mean of the two reciprocal halves

A one-sample t-test against 0 asks whether a group learned at all; a Welch t-test compares two groups without assuming equal variances. The replicate (not the individual fly) is the unit of n, because flies within one tube are tested together.

Tips & common mistakes
  • Leave out flies that stayed in the elevator: they made no choice.
  • Check odor balance first: untrained flies should split about 50/50.
  • Aim for 6 or more replicates per group; PIs are noisy.
